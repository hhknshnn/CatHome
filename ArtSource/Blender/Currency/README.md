# Ortak pati jetonu

`build_runner_coin.py`, 7 Eylül 2026 kullanıcı isteğiyle yenilenen ortak coin modelini ve ikonunu üretir. Headless Blender 5.2, Y-up Unity dışa aktarımı; kaynak disk XY, kabartma +Z. Unity'deki bir defalık Y=180 yönü korunur.

Kenar yivleri, sürekli işlenmiş halkalar, yumuşak pati kabartması ve saten altın yüzey aynı modelin parçasıdır. 1536×1536 şeffaf ikon gerçek modelin stüdyo renderıdır. HUD, mağaza ve Runner aynı kanonik dosyaları kullanmaya devam eder. Model veya ikon yolu/kimliği değiştirilmez.
