## Kullanılan istem

Use case: stylized-concept / ui-mockup.
Create ONE polished art-direction concept board for a real existing 3D cat-care game called CAT HOME. The user explicitly wants ALL main screens, buttons and UI animations redesigned in a VIBRANT MAGICAL STORYBOOK CARTOON style. This is a REVIEW CONCEPT, not an implemented game screenshot.

Input image 1 is the current gameplay room: preserve its existing room geometry, furniture identities, relative positions and actual angular low-poly cat anatomy. Image 2 is the current main menu and its actual three cats. Image 3 is the existing shop and its actual product designs. These are content references, not style references. Redesign the UI composition and art direction decisively.

Make a coherent 2x2 board in high-resolution landscape, about 3072x2048. A tiny calm heading above the board reads "CAT HOME — GÖRSEL TASLAK".
TOP LEFT: new MAIN MENU landscape screen. Use the real orange, black and grey low-poly cats from image 2, retain their actual body/head proportions and faceted contours; joyful warm eyes via lighting, no bigger eyes, no baby kitten redesign, no realistic fur. Stage them on the existing rug against an illustrated-in-3D storybook interior. A custom playful CAT HOME wordmark, strong inviting coral-orange "Devam et" button, smaller "Yeni oyun", quiet settings control. Rich cyan and lilac architecture, golden morning window light, appetizing tangerine accents. Artful, spacious composition rather than a white business website split screen.
TOP RIGHT: new GAMEPLAY landscape screen using the same actual room and furniture placements as image 1. Transform materials/light/color: deep periwinkle-teal walls, warm peach wood, turquoise upholstery, selected coral sofa cushions, soft blue-purple shadows, clean warm edge lighting and deliberate bold color grouping. Reduce distracting all-over gold by using warm painted trims except real coin icons. Keep room walkways clear. Existing cat clearly readable against the floor, preserving its scale/anatomy. Compact top needs HUD labeled "Tokluk", "Su", "Enerji"; discrete profile and currencies; tactile small joystick and integrated bottom navigation "Mağaza", "Oda", "Kedim", "Oyunlar". Dense information no longer competes equally. Keep strong readable contrast and generous touch targets.
BOTTOM LEFT: new SHOP landscape screen. Header "Mağaza". A colorful but refined illustrated 3D boutique interface: indigo header, cream content field, warm peach and aqua display backdrops, actual existing basket, scratching post and cushion models prominently displayed, not newly invented products. Three generous product cards labeled "Top sepeti", "Tırmalama direği", "Uyku minderi". Buttons "İncele". Clear tab hierarchy and corner close button. A coherent game interface, not SaaS dashboard or rows of generic white rounded rectangles.
BOTTOM RIGHT: a matching UI MOTION / COMPONENT direction panel on a calm cream background. Header "Hareket ve butonlar". Show a single tactile coral button in three small successive states labeled "Normal", "Basılı", "Bırakıldı", with restrained squash and settle and a short dotted arrow sequence. Below show a compact reward popup titled "Harika!" with a paw coin emblem and three small purposeful sparkles. Also show sample indigo secondary button and selected aqua tab. No endless confetti, no oversized glow, no garish rainbow, no thick black comic outlines.

Style: sophisticated premium mobile 3D cartoon game art direction, lush saturated yet carefully limited palette, clean rounded UI geometry with crisp dark colored borders and subtle offset dimensional edges, confident friendly rounded typography, direct tactile feedback. Visually magical through color and lighting, not clutter or added fantasy props. All 4 panels unmistakably the same designed game. Do not add castles, fairies, plants, butterflies, furniture, characters or new gameplay mechanics. No photorealism, no fur, no new skeletal anatomy, no depth-of-field blur hiding the scene, no extravagant raytracing look impossible for stylized Unity mobile. Show an achievable stylistic goal with existing low-poly models. Fine surface gradients and selective hand-painted textures are welcome. Do not reproduce the old cold white/blue interface. Keep Turkish text crisp and use only the stated short strings.
